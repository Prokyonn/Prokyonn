## How I work

I run a small team of AI agents. Each gets its own branch, database and URL. Some build features, some review pull requests, one orchestrates the rest.

**They draft. I decide.** Nothing is pushed, posted or merged without my yes. The agents write code. The architecture is still my job.

They keep notes on what they learn, and the useful ones end up in a shared knowledge base.
